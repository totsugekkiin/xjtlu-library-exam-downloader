**XJTLU Library Exam Paper Downloader**

在 XJTLU 图书馆试卷查看器中，一键保存当前 PDF。使用现有登录状态，不保存账号、密码、Cookie 或 Token。

Download the current PDF from the XJTLU Library exam viewer. The extension uses your existing signed-in session and stores no credentials.

## 安装 / Installation

1. 点击上方按钮下载 ZIP 并解压 / Download and extract the ZIP above.
2. 打开 `edge://extensions` 或 `chrome://extensions`。
3. 开启开发者模式，选择“加载解压缩的扩展”。

## 使用 / Usage

1. 登录 `etd.xjtlu.edu.cn` 并打开试卷查看器。
2. 点击扩展图标。
3. 点击“下载 PDF”。

Open an exam paper in `etd.xjtlu.edu.cn`, click the extension, then click **下载 PDF**.
